# Poker Night Journal — Response

A response to [Poker Night Journal](Poker%20Night%20Journal.md). Nothing here is decided.

## Fits

- A few optional sentences attached to an evening, separate from the money.
- Not every hand, and not a hand-history format.
- One object: a note. A hand, a bluff, or a funny moment is what the note is about.
- Adding and editing notes after the evening is closed. The money can stay frozen while the story is still writable.
- Reading the notes on that evening's summary. History only needs a count.
- Linking a note to existing players later, if the text habit exists.
- Leaving the evening's name and place on the session. A note does not have to title the evening.

## Fits less

- Treating a hand as its own record, with cards, positions, or a link to a hand that was never stored.
- A form: title, players, time, several photos, and video, when the principle is one short step.
- A cover image on the history card. That card is for the money, and a name and place already identify the evening.
- Video, a session media library, and photos stored with the money.
- A composer on the live evening screen beyond one sentence.
- Sharing, accounts, export, search, a gallery, and a timeline. A note list on the summary already is the timeline. Sharing is an access question, larger than the journal.

## Decisions worth making

Still open. Each one is the choice that would tighten the idea.

1. **Is a note the only object?** A hand would be a note about a hand, with no separate hand record unless free text turns out to be insufficient.
2. **Can notes change after the evening is closed?** The money, date, name, and location would stay read-only. Notes could still be added, edited, and deleted, because they are memory rather than the ledger.
3. **Is the first version text only?** One field, saved to that evening, shown on the summary. A title, players, a time, and a photo would wait until the text is actually used. If a title is needed, the first line can be the title.
4. **Who is it for?** The operator, with the phone passed around as it is today. Accounts, a shared album, and export would stay out until someone misses them.
5. **What is a photo, when one is added?** One image on a note. Video, a cover, and a separate pile of session media would stay out. Where the file is stored, and how large it may be, would be decided then. The file would need its own storage, separate from the money tables.
